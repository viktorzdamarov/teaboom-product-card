# Карточка товара Teaboom

Верстка блока карточки товара «Ананасовый улун» ([оригинал](https://teaboom.ru/product/ananasovij-ulun)).

## Как открыть

Откройте файл `index.html` в браузере.

## Структура

- `index.html` — разметка
- `css/style.css` — стили
- `scss/style.scss` — исходник стилей (если правите SCSS: `sass scss/style.scss css/style.css`)
- `js/main.js` — переключение фасовок
- `assets/` — картинка товара
